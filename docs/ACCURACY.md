정답지: Python **Skyfield 1.55 + JPL DE421** 로 만든 `tests/fixtures/reference.json` (`npm run fixtures`).
조건: 5곳(파주·서울·시드니·레이캬비크·싱가포르 — 북반구·남반구·적도·고위도) × 6개 시각(2024~2030년, 계절 고루) — 테스트 `tests/unit/accuracy.test.ts`.
비교는 대기 굴절 **없이** 했습니다 (화면에는 굴절을 넣어 지평선 근처가 약 0.5° 높게 보임).
